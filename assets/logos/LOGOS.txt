Review site logos used by the Rating widget
=============================================

Every file here holds the original vector shapes published by its source, listed below.
Nothing was redrawn, traced or recoloured. Only three things were changed:
  - the viewBox is set so each logo is centred with the same space around it inside the
    round badge (the shapes themselves are untouched);
  - editor metadata and unused attributes were removed;
  - where a file also holds a wordmark (BBB, Nextdoor), only the symbol shapes are kept.

All logos are trademarks of their owners. They are included only so a site can point to
its own profile on that review site. If a logo needs to be replaced, keep the file name
(google, facebook, yelp, bbb, angi, nextdoor, houzz, thumbtack) so saved blocks keep working.

Placement
---------
The widget shows each logo on a white circle, filling the circle (the space around the logo
is part of the file). The editor lists the same files.
